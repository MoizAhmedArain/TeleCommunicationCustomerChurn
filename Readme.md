# Customer Churn Prediction 

This project predicts customer churn using a **Random Forest Classifier**.  
It includes a **Streamlit UI** for interactive predictions with dropdowns, radio buttons, and sliders — making it simple for users to test scenarios without typing raw data.

---

##  Features
- Preprocessing pipeline with one-hot encoding for categorical features.
- Random Forest model trained with class balancing.
- Interactive Streamlit app:
  - Dropdowns for contract type and offers.
  - Radio buttons for payment method and internet service.
  - Sliders and number inputs for tenure, monthly charges, and profit.
- Clear prediction output with churn probability.
